# 📅 **DoDate**
### **Front end para para nuestra app de reservas de espacios DoDate.**

---

## 🎨 **Frontend**

Se esta usando **React** como framework/librería principal.  

### **Stack utilizado:**
- **React**  
- **Vite**  
- **TypeScript**  
- **Tailwind CSS**  

---

## ⚙️ **Posibles Herramientas necesitadas (generado con IA)**

### ⚙️ **Backend**
- **FastAPI** – Framework moderno para APIs en Python  
- **Uvicorn** – Servidor ASGI para correr FastAPI  
- **Pydantic** – Validación de datos y esquemas  
- **Python 3.10+**  

---

### 🗄️ **Base de Datos**
- **PostgreSQL** – Base de datos relacional  
- **SQLAlchemy 2.0** – ORM para manejar la base de datos  
- **Alembic** – Migraciones de base de datos  

---

### 🔐 **Autenticación y Seguridad**
- **JWT (JSON Web Tokens)** – Autenticación de usuarios  
- **OAuth 2.0** – Integración con servicios externos  
- **Microsoft Entra ID (Azure AD)** – Autenticación con cuentas institucionales  

---

### 📅 **Integración de Calendario**
- **Microsoft Graph API** – Para crear y gestionar eventos en Outlook  
- **httpx** – Cliente HTTP asíncrono para consumir APIs externas  

---

### 🔄 **Tareas en Segundo Plano (opcional)**
- **Celery o RQ** – Para tareas como envío de correos o sincronización  
- **Redis** – Broker para colas de tareas
